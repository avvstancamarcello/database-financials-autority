🔒 Privacy Policy

Informativa sulla protezione dei dati personali

Ultimo aggiornamento: 6 Gennaio 2026

✅ QUESTA APPLICAZIONE NON RACCOGLIE, NON MEMORIZZA E NON CONDIVIDE ALCUN DATO PERSONALE DEGLI UTENTI

1. Introduzione

Il Database Internazionale delle Autorità Finanziarie è un'applicazione web educativa e informativa creata da Avvocato Marcello Stanca, con sede a Firenze, Italia. Questa privacy policy spiega come vengono trattati i dati degli utenti che visitano questa applicazione.

2. Dati Personali Raccolti

NESSUN DATO PERSONALE VIENE RACCOLTO. Questa applicazione è progettata per funzionare completamente senza richiedere, memorizzare o trasmettere alcuna informazione personale identificabile degli utenti.

Cosa NON raccogliamo:

  • Nome, cognome o informazioni identificative
  • Indirizzi email o numeri di telefono
  • Indirizzi fisici o di residenza
  • Dati finanziari o bancari
  • Indirizzi IP o dati di geolocalizzazione
  • Cookie di tracciamento o profilazione
  • Dati di navigazione tramite strumenti di analytics

3. Dati Tecnici

L'applicazione utilizza tecnologie standard del web come HTML, CSS e JavaScript. Tutto il codice viene eseguito localmente nel browser dell'utente. Le uniche interazioni con server esterni sono:

  • Hosting su GitHub Pages (https://pages.github.com) - GitHub potrebbe raccogliere dati tecnici standard come descritto nella loro Privacy Policy
  • Caricamento di librerie CSS esterne (flag-icons, leaflet) da CDN pubblici

4. Progressive Web App (PWA)

Questa applicazione utilizza un Service Worker per consentire il funzionamento offline. I dati memorizzati nella cache del browser includono:

  • File HTML, CSS e JavaScript dell'applicazione
  • Database JSON delle autorità finanziarie
  • Immagini e icone

Questi dati sono memorizzati localmente sul dispositivo dell'utente e possono essere eliminati in qualsiasi momento cancellando la cache del browser.

5. Cookie e Tecnologie Simili

Questa applicazione NON utilizza cookie per tracciare, profilare o memorizzare informazioni sugli utenti. L'unico storage utilizzato è il Service Worker cache, necessario per il funzionamento offline della PWA.

6. Servizi di Terze Parti

L'applicazione non integra servizi di analytics, advertising o social media tracking. Gli unici collegamenti a servizi esterni sono:

  • Link diretti ai siti web ufficiali delle autorità finanziarie
  • Librerie CSS/JS caricate da CDN pubblici (nessun tracciamento)

7. Diritti degli Utenti (GDPR)

Poiché questa applicazione non raccoglie dati personali, non è necessario esercitare diritti GDPR come accesso, rettifica o cancellazione. Non essendoci dati personali trattati, non esistono dati da gestire.

8. Sicurezza

L'applicazione è servita tramite HTTPS (protocollo sicuro) da GitHub Pages. Non raccogliendo dati personali, non ci sono rischi di violazione di dati personali degli utenti.

9. Minori

Questa applicazione è accessibile a tutti, inclusi i minori di 16 anni, in quanto non raccoglie alcun dato personale.

10. Modifiche alla Privacy Policy

Eventuali modifiche a questa privacy policy saranno pubblicate su questa pagina con aggiornamento della data in alto.

12. Conformità Normativa

Questa applicazione rispetta:

  • GDPR (Regolamento UE 2016/679) - Regolamento Generale sulla Protezione dei Dati
  • Codice Privacy Italiano (D.Lgs. 196/2003 e successive modifiche)
  • Direttiva ePrivacy (2002/58/CE)

Non raccogliendo alcun dato personale, l'applicazione è pienamente conforme a tutte le normative sulla privacy senza necessità di ulteriori adempimenti.

In sintesi: Usa questa applicazione con completa tranquillità. La tua privacy è totalmente protetta perché non raccogliamo alcun dato.
